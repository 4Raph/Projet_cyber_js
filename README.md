# CyberShield — Projet JavaScript Cybersécurité

OSMONT Raphaël, BOBIN JUNCA Nils, GRANGÉ Mattéo

CyberShield est une application web interactive développée en JavaScript permettant de sensibiliser à la cybersécurité à travers plusieurs outils : analyseur de mot de passe, chiffrement, détection de phishing, actualités cyber, quiz et génération de rapport.

## Fonctionnalités

### Analyseur de mot de passe

- Vérification de la robustesse
- Barre de sécurité visuelle
- Niveau : faible / moyen / fort

### Chiffrement

- Chiffrement César
- Déchiffrement César
- Force brute
- Chiffrement Vigenère
- Déchiffrement Vigenère

### Détecteur de phishing

- Analyse expéditeur
- Analyse objet
- Analyse message
- Score de danger
- Liste des raisons

### Dashboard Cyber

- Chargement d'actualités
- Filtre critiques
- Recherche
- Niveau d'alerte

### Quiz Cyber

- 10 questions aléatoires
- Timer
- Score dynamique
- Streak bonus
- Barre de progression
- Top 5 scores

### Générateur de rapport

- Résumé des interactions utilisateur
- Modal popup
- Export JSON
- Impression

## Technologies utilisées

- HTML
- CSS
- JavaScript
- localStorage
- JSON
- Blob (export rapport)
